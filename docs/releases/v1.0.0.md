# MapXProp API 1.0.0

Stable product baseline, September 2026. Paired with frontend tag `v1.0.0`; production remains online. Fixes after this baseline should use a new patch release.

Publishing now requires an uploaded property photo, contact name/phone/role, valid optional contact email, applicable prices (unless price on request), and a title of at most 160 Unicode characters. Existing required title/description, coordinates, province, category, contact authority, numeric and media ownership checks remain in force. Infinite numeric areas/prices are rejected.

Incomplete drafts remain permitted. Edits without media replacement retain existing media. Replacing media with no property image is rejected. Videos, panoramas and event floor plans do not satisfy the photo requirement.

No new database migration is needed. Existing public listings are not rewritten by this release.

The backend suite passes with an isolated PostgreSQL database, including every selectable category route, upload ownership, explicit edits, last-photo rejection, moderation, saved listings and concurrent idempotent submissions. Detailed release evidence is retained in workspace `work/listing-v1-audit-2026-09-26/`.
