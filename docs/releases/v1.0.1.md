# MapXProp API 1.0.1

Consolidates whole-building apartments into `hotel_resort`, with `apartment` or `serviced_residence` as the hospitality subtype. Monthly single-room and multi-unit rentals retain the apartment category.

- Migration 0178 updates existing building classifications, use cases and discovery channels, while preserving listing IDs/slugs, content, media, offers and other details. Removes the separate Business/apartment taxonomy mapping.
- Normalizes requests from older clients and drafts to the same classification.
- Apartment keywords and old type filters continue to match apartment hospitality subtypes. Serviced searches include serviced residences.

Validation: Go suite with isolated PostgreSQL, all 23 publishing/editing category cases including the hospitality apartment subtype, normalization regression cases, and six migration fixtures with preservation and replay checks. Paired with web 1.0.4. Evidence: workspace `work/hospitality-apartments-2026-09-27/`.
